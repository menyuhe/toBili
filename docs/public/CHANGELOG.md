# 更新记录

## 0.2.29 · 2026-11-14

- 账号菜单与挂机运作增加独立登录检查，区分登录正常、暂无法确认与需重新登录。
- 读取超时显示重试提示；网络或钥匙串问题不会直接判定登录失效。
- 登录失效保留原账号资料和任务设置；重新扫码后旧检查结果不会覆盖新状态。
- 修正恢复场景的重试时间计算，保持原周期与冷却规则；任务结果注明时间，新成功结果替换当前旧错误。
- 更新首页介绍、使用指南与常见问题，重录全部界面截图和两组流程 GIF。

同一系列升级保留 Windows 原 data 或 Mac 原应用数据。替换前退出程序并备份；无需新建数据目录。


## 0.2.27 · 2026-11-14

本次同步 Windows、macOS 与开源核心。账号凭据、参与历史和任务设置继续保存在本机，公开目录只传递活动资料。

- 统一活动列表、待参与、订阅源、清理与设置的布局；搜索按钮展开输入框，收起时清空搜索词，筛选集中在弹窗。
- 转发与评论类的展示合并为「转发抽奖」，互动抽奖和预约抽奖保持区分，原始类型不改写。
- 挂机运作显示完整 UID、每个账号已缓存的未读数；没有读取的账号显示「—」。
- 开奖核验增加「缺 UP 信息」筛选，统计与列表对应；单条没有公告不会中断整轮。
- 官方组件与索引优先；结果检查采用退避，未到开奖时刻的条目延后检查。
- 日志按实际任务分栏，支持完整异常详情与忽略记录；展开日志不压缩活动表格。
- 消息读取使用按账号隔离的短期缓存；本机标记已看不重新抓取全部消息。
- 修正打包版本元数据不一致，构建时检查核心、前端与包版本。

升级请保留 Windows 程序同级 data，macOS 覆盖原应用。数据库自动升级，升级前备份；不要用旧程序打开升级后的数据库。
