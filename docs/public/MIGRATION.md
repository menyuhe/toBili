# 升级与历史版本迁移

## 从 0.2.x 升级到 0.2.29

退出应用并备份数据后，Windows 覆盖原目录中的 EXE，保留同级 `data/`；Mac 覆盖「应用程序」中的原应用。账号凭据、参与历史和定时设置继续沿用，不需要另建数据目录或重新扫码。数据库会自动升级，升级后不要用旧程序打开同一份数据库。

## 从历史版 v20261103 迁入

以下仅适用于历史版 v20261103，属于不同实现，不能直接覆盖它的数据目录。旧版发布 `v20261103` 和历史提交保留，方便查看与回退。

1. 先退出旧版，备份旧安装目录与数据。两个版本不要同时为同一个账号执行参与或清理。
2. 在新文件夹放置新版 `toBili.exe`，重新扫码添加自己的账号。
3. 添加订阅源或读取公开目录，重新检查各账号的任务周期、范围和参与节奏。
4. 旧版参与历史、私信标记和任务配置不会自动迁入当前版本；不要把旧数据库直接覆盖到新 `data/`。需要保留的历史可继续在旧版只读核对。
5. 确认新版本符合使用需要后再启用定时任务。截止不代表未中奖；历史转发清理仍需核对具体记录。

当前开源核心与旧代码是不同实现。历史标签保留原许可证，主分支以当前 LICENSE 为准。

公开站点现在提供新版入口与匿名奖品目录。旧站数据库保留备份；旧版兼容 API 的存在不表示新版继续依赖旧站登录与同步方式。
