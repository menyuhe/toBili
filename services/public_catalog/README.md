# 公开活动奖品目录

独立的公开数据库：匿名读取、密钥发布。它不打开私有资料簿数据库，也不挂载账号、消息、修订审批或执行权限接口。

线上查看：`https://tobili.4wdo.cn/public/`。分页 API：`GET /public/v1/catalog?after=0&limit=100`。

## 数据边界

只接受 `PublicPrize` 字段：动态号、公开作者 UID／名称、奖品、参与类型、发布时间、开奖时间或仅开奖日期。未知时间为 null；日期精度不会伪造成具体分钟。账号、Cookie、参与记录、私信、设备信息、模型密钥、原始正文和修订审批记录均不在协议内。

同一动态修正后取得新修订序号。读端使用响应 `next` 继续读取，`more=false` 表示当前批次到尾；不能用旧目录的动态号游标替代修订序号。重复发布相同内容不会产生新修订。

普通版只读取本协议的资料与修正；手工奖品锁与已有本机日期优先，不导入参与资格或自动入队。官方目录由常开设备发布已审核的汇总资料，普通版只有读端。旧客户端目录接口保留兼容，不再作为新版默认数据源。

## 自建

安装项目 Python 依赖，将 `core/src` 加入 PYTHONPATH。使用 `services.public_catalog.server.create_app(database_path, publisher_key)` 构建 ASGI app，再由 Uvicorn 启动。发布密钥至少 32 字符，由部署者随机生成，不写入源码。读写 URL 分别是 `GET /v1/catalog`、`POST /v1/catalog`，写入需要 `Authorization: Bearer ...`，请求体为 `{"items":[...]}`，每批最多 100 条。

反向代理限制请求体、仅提供 HTTPS；服务用独立系统用户运行，只允许写公开数据库目录。部署者应备份该 SQLite 数据库；发布端保留原始资料，但不能把私有数据库备份放进静态文件目录。
